# British Airways Customer Booking Prediction

## Project Overview

This project predicts whether a customer will complete a booking using machine learning techniques. The project follows a complete data science workflow from data preprocessing to model evaluation and business insights.

---

## Project Workflow

- Data Cleaning
- Duplicate Removal
- Exploratory Data Analysis (EDA)
- One-Hot Encoding
- Train-Test Split
- SMOTE for Class Balancing
- Random Forest Classifier
- Hyperparameter Tuning (RandomizedSearchCV)
- Cross Validation
- Model Evaluation
- Feature Importance Analysis
- Business Insights

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Imbalanced-learn (SMOTE)

---

## Model

- Random Forest Classifier
- RandomizedSearchCV
- 5-Fold Cross Validation
